# Organic growth playbook

The acquisition loop is: specific astronomy question → trustworthy static answer → calculation for the reader's location → related guide or return visit.

## Editorial workflow

1. Select one uncovered feature from `content/features.json`.
2. Record the reader's decision, competing intent, primary sources, CVAN-specific worked example, tool target, and related pages.
3. Draft one canonical answer. Update an overlapping guide instead of creating a keyword variation.
4. Verify every numerical claim and model limitation; add it to the source ledger.
5. Add the article to `content/guides/articles.mjs`, map the feature, build, and run content checks.
6. Inspect the rendered desktop and mobile page before publication.

## Distribution assets

Create a link-worthy latitude comparison graphic, printable observing checklist, and methodology page. Prepare astronomy-club and resource-directory outreach drafts around a specific useful guide, but do not send them without authorization. Any community sharing should follow local rules and disclose the owner's connection to CVAN.

Avoid mass city pages, copied definitions, artificial backlinks, and pages created only for query variations. Regional pages require distinct verified local value and current access information.
